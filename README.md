# How to play to Heroes of Might and Magic III in Vietnamese

1. Buy _Heroes of Might and Magic III Complete Edition_ on GOG (not the HD version)
1. Install the game
1. Download VCMI (free)
1. Install VCMI
1. When installing VCMI, specify the location of the base game's `Data`, `MP3`, and `Maps` folders.
1. Set the language to _Vietnamese_
1. Install the _Bản dịch tiếng Việt_ mod
1. Launch the game

# Cách chơi Heroes of Might and Magic III bằng tiếng Việt

1. Mua _Heroes of Might and Magic III Complete Edition_ trên GOG (không phải phiên bản HD)
1. Cài đặt game
1. Tải VCMI (miễn phí)
1. Cài đặt VCMI
1. Khi cài đặt VCMI, hãy chỉ định vị trí các thư mục `Data`, `MP3` và `Maps` của game gốc.
1. Đặt ngôn ngữ thành _Tiếng Việt_
1. Cài đặt bản mod _Bản dịch tiếng Việt_
1. Khởi chạy game
